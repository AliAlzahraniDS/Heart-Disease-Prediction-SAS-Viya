
# Heart Disease Prediction – SAS Viya

## Project Overview

This academic group project explores heart disease prediction using data mining and machine learning techniques in SAS Viya.

The project focuses on data preprocessing, exploratory data analysis, classification, and patient clustering to identify patterns associated with heart disease.

## Project Objectives

- Prepare and clean clinical and demographic data.
- Explore relationships between heart health variables.
- Build and compare Decision Tree models.
- Apply K-Means clustering to identify patient subgroups.
- Evaluate model performance and interpretability.

## Methodology

### 1. Data Preprocessing
- Inspected clinical and demographic variables.
- Cleaned and prepared the dataset.
- Examined outliers and summary statistics.

### 2. Exploratory Data Analysis
- Created box plots and scatter plots.
- Explored relationships between clinical variables.
- Examined correlations and patient characteristics.

### 3. Decision Tree Modeling
- Developed multiple Decision Tree models.
- Compared model performance using evaluation measures.
- Selected Decision Tree (2) as the preferred model.

### 4. K-Means Clustering
- Applied K-Means to segment patients.
- Compared different clustering solutions.
- Selected the three-cluster solution (km_3).

### 5. Cluster-Based Modeling
- Built additional Decision Tree models for patient subgroups.
- Explored how clustering could support classification.

## Tools & Technologies

- SAS Viya
- Data Mining
- Machine Learning
- Exploratory Data Analysis (EDA)
- Decision Trees
- K-Means Clustering

## Key Findings

- Data preprocessing supported more reliable analysis.
- Decision Trees provided interpretable predictions.
- K-Means helped identify patient subgroups.
- Combining clustering and classification offered additional analytical insights.
